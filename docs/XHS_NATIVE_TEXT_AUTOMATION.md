# 小红书原生“文字配图 / 文转图”自动化设计

## 结论

可以把“原生文转图”也纳入自动发布链路，不必永远让用户手工复制粘贴。

公开的第三方自动化技能已经描述了网页版创作流程：上传图文 → 文字配图 → 粘贴文案 → 生成图片 → 选择卡片风格 → 下一步 → 填标题 → 发布。这说明当前至少存在可通过浏览器 UI 操作的路径，但小红书可能做灰度、账号差异或 UI 改版，所以 V0.8 只交付可测试的 Playwright scaffold，等 Mac 到手后再实机校准 selector。

## 最终链路

Content OS：
1. 选题总编只给 1 个主推 + 1 个备选。
2. Terra 产 Brief / 正式稿；Luna 做总编复核。
3. 事实核验通过。
4. 生成 `native_text_plan`：最终标题、平台可直接粘贴正文、推荐模板、备选模板、预计页数。
5. 用户只做最终审核并点“通过”。

Mac Publisher：
1. 领取已审核 publish job。
2. 使用 `xhs-publisher` 独立浏览器 Profile。
3. 打开 Creator Center。
4. 进入文字配图。
5. 粘贴 `input_text`，生成平台原生图片。
6. 自动优先选择推荐模板；不存在则降级到备选。
7. 填标题。
8. 最终发布（可配置自动或停在最后一步）。

## 不做的事情

不绕验证码、不做设备指纹伪装、不逆向私有接口、不在研究小号上发布、不在发布大号上做批量搜索研究。
