# XHS Native Text Publisher (future Mac module)

This folder is intentionally a **scaffold**, because v0.8 is usable without a Mac.

When the always-on Mac is available, install Playwright and log in once with the **publisher/main account** profile. The script consumes the `native_text_plan` generated by Content OS and follows the normal creator UI:

`发布笔记 → 上传图文 → 文字配图 → 粘贴 → 生成图片 → 选择模板 → 下一步 → 标题 → 发布`

Default behavior stops before the final publish click. After the Content OS approval gate is proven reliable, `--auto-publish` can click the final button too.

Safety constraints:
- dedicated publisher profile; never share the research-account profile;
- no private API reverse engineering;
- no CAPTCHA or slider bypass;
- if verification/UI mismatch appears, fail closed and notify the user;
- low-frequency single-account use only.

The creator UI can be A/B tested or changed. Selectors must be verified on the user's own Mac before unattended use.
