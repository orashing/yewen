# 零 API 热点雷达

1. 打开「选题 → 多源热点雷达」。
2. 配置检索源与 watch queries，例如：
   - 北京高考
   - 北京650分
   - 北邮计算机
   - 金融专业
   - 普通家庭 学金融
   - 北京孩子 出京
   - 985 冷门专业
3. 点「复制联网扫描提示词」。
4. 在支持联网检索的 ChatGPT/Codex 对话里发送该提示词。
5. 将返回的 JSON 粘回「导入热点」。
6. 系统保存至 `trend_signals`，并按搜索意图、新鲜度、家长匹配、转化价值进行排序。
7. 点击「转成选题」进入原有 Brief → 写稿 → 核验 → 卡片流程。

注意：该模式不等于直接读取小红书 App 内部实时热榜。只有能被联网工具实际发现的公开页面才应带来源；其余信号必须低置信度/待人工确认。
